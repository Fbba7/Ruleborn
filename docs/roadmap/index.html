Merge the two checkers into one

Done from here

v3.1 ships its own build checker, and it is good: it pins canonical constants in data/, recounts §26.1 from the tables, re-derives each creature’s size band from its head count rather than trusting the column, and hashes generated blocks so a hand edit fails the build.

Two checkers over one artefact is the fault the register is about, applied to the tools. Merge them, keep every check from both, and make the banned-phrasing checks derive from data/ rather than from a hand-written list — which is §31.4’s own rule pointed at the checks.

Done: tools/check_document.py. 69 checks over one artefact — it takes the HTML and derives the text from it, so the two halves cannot read different versions, which two checkers pointed at two paths always could.

The merge needed a verdict neither had. v3.1’s checker exits non-zero on any failure, because it is a gate; this repository’s always exits zero, because most of what it reports is an open register item. So every check now declares which it is, and there are four outcomes rather than two: PASS, OPEN (failing, and its register item is open — expected), RETIRED (a tracked check that now passes: close the item) and BREAK. On v3.1: 56 pass, 13 open and tracked, nothing broken — so the document checks can be a build gate for the first time.

Done from here

The market-standard shape for a mobile game client, in Godot's own terms. Views (scenes) only draw and send intents. Under way from here

The largest gap and the system most likely to fail §30.7's premise 3 — that delegated control still feels like agency. Drafted in spec/movement.md; make felt control a gate on the slice, not a polish item.

The buildable half is built. sim/path.rs is §12.18's pathfinder: breadth-first, four neighbours in a fixed north-east-south-west order, ties by tile index. Breadth-first rather than A* because A*'s answer depends on the heuristic and on how a priority queue returns equal keys — two places correct implementations differ. Terrain slows the walk and cannot bend the route, which is the spec's rule: a pathfinder that went round mud would be choosing for the player.

§12.18's four behavioural clauses are tests rather than prose — no re-routing, no picking a different door, crew pass through one another, the command and never the path.
