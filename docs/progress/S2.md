## IQ-import-check: notes

Done 16 November 2026, on main 40d457c6 merged into
claude/ui-screens-home.

- **Method.** (1) A static pass over `git ls-files`: each `.import` and
  `.uid` has a tracked source; each importable source (images, fonts,
  audio, models, CSV) has a tracked `.import`; each `.gd`, `.gdshader`
  and `.gdextension` has a tracked `.uid`; no UID is used twice; each
  `.import`'s `source_file` names its own source; each `[ext_resource]`
  in a `.tscn` or `.tres` cites its target's current UID; each `uid://`
  in a script or `project.godot` names a known resource. (2) A clean
  import: `bash client/build.sh` on a fresh container (no `.godot/`),
  then a second worktree of the same head with no `.godot/`, imported
  twice with Godot 4.7.2 headless (`--import`), then `git status
  --ignored` on both. (3) Godot's `.godot/uid_cache.bin` from that import
  decoded and compared, path by path, with the UIDs the tracked files
  hold.
- **Counts.** 1,065 tracked sidecars: 576 `.import`, 489 `.uid`; 1,059
  resources carry a UID (the sidecars plus the `.tscn` and `.tres`
  headers).
- **Clean import.** Both imports exited 0. No tracked file changed and no
  untracked `.import` or `.uid` appeared, in the main checkout or the
  scratch worktree. The import log has no UID warning or error.
- **UID cache.** 1,059 entries, 1,059 tracked UIDs, 0 mismatches, 0
  entries without a tracked sidecar.
- **Static pass.** No missing `.import` or `.uid`, no duplicate UID, no
  stale `ext_resource` UID, no unknown `uid://` reference. Three orphans:
  `client/tests/_only.gd.uid` (added in d070e02b, 21 October),
  `client/tests/shots/budget_parts.gd.uid` and
  `client/tests/shots/probe_tmp.gd.uid` (added in 3748ce5b, 27 October).
  Their scripts were never tracked (scratch scripts whose `.uid` was
  committed by mistake). Godot leaves them out of its UID cache, so they
  do no harm at run time, but they are dead files that a later script of
  the same name would inherit. Sent to the lead as S2-R29.
- **Observed, not a mismatch.** `client/i18n/content.csv`,
  `countries.csv` and `strings.csv` (`importer="keep"`) show up in
  Godot's scan actions on every start, even the second import of an
  unchanged tree. That is how Godot treats "keep" files (nothing is
  written), so no request.
- **Not filed.** No other mismatch, so no other request.
