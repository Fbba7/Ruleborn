Each 3D and interface track's notes: what was done, the stills it was judged
by, what is still worse than the design, and a "Stopped here" section for
whoever picks the track up next. File names mix track numbers and subjects,
so here is which is whose:

Every file is in time order and every stop is headed `## Stopped here`, with
the session, wave or time in brackets; **the last one in a file is the
latest**, and is where to start reading when picking a track up.
