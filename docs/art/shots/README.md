# Stills

The stills each track judged its work by, rendered from the real client
(`tools/render/shoot.sh`) and compared with the design's. One folder per
track or session:

| Folder | Track |
|---|---|
| `t1-characters/`, `t1b/`, `t1c/`, `t1d/` | T1 Characters (sessions 1, 2, 3 and wave 5) |
| `look/` | T2 Look |
| `kit/` | T3 Kit |
| `universe/` | T4 Universe |
| `t5/` | T5 Heist |
| `T6/` | T6 Realm screens |
| `t7/` | T7 Character screens |
| `t8/` | T8 Law effects |
| `ui-kit/` | T9 UI kit |
| `ui-screens/` | T10 Screens |
| `auth/` | T11 Sign-in |

T14's images are in [`docs/art/ui-quality/`](../ui-quality/report.md).
Progress files often cite a still by its bare name; its folder is its track's
row here. How to render one: [`docs/guides/client.md`](../../guides/client.md#rendering-a-still).
